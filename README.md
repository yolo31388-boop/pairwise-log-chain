# pairwise-log-chain

审计日志一被篡改，追责就断链：事件哈希只对 message 做，时间戳和操作者可以被改；JSON 序列化 key 顺序不稳定，同一事件在不同节点算出不同哈希；批量写入时 seq 跳号，删除中间记录无法发现；日志里直接写了手机号和身份证，合规扫描不过；多节点时钟不同步，前后事件时间倒挂；归档后只保留最后 30 天，旧链头没有外部锚定。audit/log_chain.py 是核心，tests/test_log_chain.py 15个红。要修的是：全字段规范化哈希；稳定序列化；连续 seq；PII 脱敏；可信时间；链头锚定与保留。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
